## 📋 Descripción del Software
Este software permite:
- Diseño hidrologico (determinacion de caudales maximos)
- Diseño de obras de drenaje longitudinal (cunetas y zanjas
- Diseño de obras de drenaje transversal (alcatanrillas en carreteras)
- Canales a flujo uniforme
- Alcantarillas de sección circular
- Variedad de obras hidraulicas
- Calculo de pérdidas de carga en tuberias
